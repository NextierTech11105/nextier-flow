Silvia's Setup

About 25 minutes. Do the steps in order. Each one tells you when it's done.

1 GitHub→2 Invites→3 Claude→4 VS Code→5 Your code→6 Perplexity
1

Make your GitHub account

2 minutes
  1. Go to github.com/signup
  2. Use your EHOA email and make a password.
  3. Pick a username.
  4. Type in the code GitHub emails you.

Done when you see your GitHub home page. Text Thomas your username.

2

Accept Thomas's two invites Wait for Thomas

1 minute

Thomas makes you an owner of two GitHub organizations: Parcelvora and EHOA Advisors.

  1. Open each "invited you" email from GitHub.
  2. Click Join.

Done when both show on your GitHub profile under Organizations.

3

Make your Claude account

3 minutes
  1. Go to claude.ai and sign up with your EHOA email.
  2. Click your name (bottom left), then Upgrade plan, then Pro.
  3. Thomas enters his card at checkout.

Done when your plan says Pro.

4

Set up VS Code

10 minutes
  1. Install VS Code from code.visualstudio.com
  2. Install Git from git-scm.com. On a Mac, open Terminal, type git and accept the install it offers.
  3. In VS Code, click the person icon (bottom left), then Sign in with GitHub, and approve in the browser.
  4. Open the terminal with Ctrl + ` (Mac: Cmd + `) and paste this:
code --install-extension anthropic.claude-code --install-extension mhutchie.git-graph --install-extension mechatroner.rainbow-csv --install-extension github.vscode-github-actions --install-extension ms-python.python --install-extension ms-toolsai.jupyter

On a Mac, if it says "code not found": press Cmd + Shift + P, run Shell Command: Install 'code' command in PATH, then paste again.

  1. Click the Claude icon in the left bar and sign in with your Claude account.

Done when the Claude panel opens in VS Code.

5

Open your code

2 minutes
  1. Press Ctrl + Shift + P (Mac: Cmd + Shift + P) and type Git: Clone.
  2. Choose Clone from GitHub, then pick parcelvora.
  3. Choose a folder, then click Open.

Done when you see README.md in the left panel.

6

RealEstateAPI in Perplexity Optional

5 minutes · needs Perplexity Pro or Max
  1. Get an API key from your RealEstateAPI dashboard. Use a separate key from EHOA's daily one, so Perplexity questions don't use up EHOA's credits.
  2. In Perplexity, go to Settings, then Connectors, then + Custom connector.
  3. Name it RealEstateAPI and paste this address:
https://mcp.realestateapi.com/sse
  1. If the form lets you add a header, name it x-api-key and paste your key as its value.
  2. If it doesn't, choose no authentication and put the key in the address instead:
https://mcp.realestateapi.com/sse?x-api-key=YOUR_KEY

Swap YOUR_KEY for your key. RealEstateAPI's own docs show this form. Treat the connector like a password: if the key ever leaks, make a new one in your RealEstateAPI dashboard. Every property lookup spends credits on your account, so check your usage after the first few questions.

Done when Perplexity can answer a question about a property address.
